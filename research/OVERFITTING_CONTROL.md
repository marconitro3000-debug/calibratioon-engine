# Overfitting Control

OpenAlphaLab treats overfitting as the default risk in alpha research.

## Implemented V3 controls

- walk-forward validation
- fold score dispersion
- parameter stability among top configurations
- Deflated Sharpe proxy
- PBO proxy
- turnover/cost drag rejection
- alpha book correlation filter

## Roadmap controls

- full combinatorial purged cross-validation
- full Deflated Sharpe Ratio
- White Reality Check / SPA test proxy
- stationary bootstrap
- regime split tests
- parameter perturbation heatmaps
